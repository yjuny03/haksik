# 학식목장 공모전 AI 기능 기준

## 최종 AI 모델
- Gemini 사용
- MockAiClient는 테스트/데모용으로 유지
- 공식 provider는 `mock|gemini`만 유지

## 핵심 AI 기능
1. AI 신고 자동 처리
- 게시글, 댓글, 채팅, 리뷰 신고 분석
- 광고/스팸, 개인정보, 도배, 고강도 욕설 자동 처리 후보
- 애매한 신고는 관리자 검토
- 사진만 있는 신고는 관리자 검토
- 텍스트+사진은 텍스트만 AI 분석

2. 관리자 사후 관리
- AI 자동 처리 결과 확인
- 처리 취소/복구 가능
- AI 분석 상태 RESTORED 기록
- 알림 및 대시보드에서 AI 처리 현황 확인

3. 신뢰도/매너온도 연동
- AI 자동 처리 시 기존 신고 제재 정책과 연결
- 복구 시 제재도 복구
- AI 단건으로 즉시 계정 잠금은 하지 않음

4. AI 맛집 추천
- 사용자 선호 음식, 위치, 가게 카테고리, 메뉴, 리뷰 기반 추천
- DB에 존재하는 가게/메뉴만 후보로 사용
- Gemini는 추천 이유와 설명 생성
- 존재하지 않는 가게를 생성하면 안 됨

## 현재 다시 맞출 방향
- ai.provider=mock|gemini 구조로 변경
- GEMINI_API_KEY 환경변수 사용
- 기존 신고/복구/알림/대시보드 기능은 유지
